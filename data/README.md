# External data used by the analysis scripts

* `icecube_deepcore_9y_sin2theta23_dm32_90pc.csv` — the official IceCube
  DeepCore 90 % C.L. contour in the (sin²θ₂₃, Δm²₃₂ [eV²]) plane, normal
  ordering, from the 2011–2019 ("9 y verification") sample. Two unnamed
  columns, 103 points, closed curve. Source: IceCube Collaboration, "Replication
  Data for: Measurement of atmospheric neutrino mixing with improved IceCube
  DeepCore calibration and data processing", Harvard Dataverse V1 (2025),
  doi:10.7910/DVN/B4RITM; copied verbatim from the pinned Newtrinos.jl checkout
  (`src/experiments/icecube/deepcore_9y_verification_sample/DeepCore_oscNext_verification_sample__sin2_theta23_dm2_32__90pc_result_bugfix.csv`).
  Publication: R. Abbasi et al. (IceCube), Phys. Rev. D 108, 012014 (2023),
  arXiv:2304.12236. Used by `scripts/82_extension_plots.jl`.
